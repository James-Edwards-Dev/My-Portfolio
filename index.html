Procedural Skier

  • C++
  • Unreal Engine

Procedural Skier is a 3rd person skiing game that I developed for my final year undergraduate dissertation project, which focused on Procedural Terrain Generation.

This project and dissertation archived a total mark of 76%!

I chose to focus on procedural terrain generation, as I enjoyed learning about the noise algorithms that can be used to create terrain height maps.

My approach to creating the terrain in was to generate two terrain height maps and sum these two terrain maps together. The noise algorithm I used for these height maps where;

  • Fractile Perlin noise (Multiple Perlin noise maps with decreasing amplitude & increasing frequency)
  • Worley noise (a noise algorithm that places random points on the heightmap and calculates each coordinate's value based on its distance from the nearest point)

Fractal Perlin Noise

Worley Noise

Combined Noise

The fractal Perlin noise creates hilly terrain with lots of bumps and the Worley noise creates smooth ridges. When summed together it creates terrain mountainous that has hilly bumps from the Perlin noise, as well as the ridges from the Worley noise.

Prototype Runner

  • C#
  • Unity

Prototype Runner is a single player movement shooter inspired by games such as Titanfall and Karlson. I created this project during the second year of my undergraduate degree for a module named 'Games Engines'. This project archived a mark of 91% which contributed to me achieving a grade of 85% for this module.

During this project I wanted to focus on character movement, so I developed multiple extra movement features for the player such as walling running and sliding using a ridge body character controller. I also created jump and boost pads that impact how the player moves and could be used when designing levels.

I also created a simple enemy AI system where enemy's could either stand in place or patrol between locations until they gain line of sight with the player. Then the enemy's either shoot at the player or chase them when they don't have line of sight.

For more details on this project you can view the projects GitHub repository
